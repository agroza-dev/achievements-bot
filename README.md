# Telegram Bot для группы

Этот бот предназначен для взаимодействия с пользователями в Telegram-группах.

## Установка

1. Склонируйте репозиторий
2. Установите зависимости: `uv sync`
3. Создайте файл `.env` на основе `.env.template`
4. Добавьте бота в Telegram-группу

## Настройка бота

Для корректной работы бота в группе необходимо:

- Добавить бота в группу как участника
- Сделать бота **администратором** группы
- Убедиться, что группа является **супергруппой** (в супергруппах пользователи могут ставить реакции на сообщения)
- Предоставить боту права на:
  - Чтение сообщений
  - Просмотр реакций на сообщения

## Особенности работы с реакциями

Для получения обновлений о реакциях на сообщения в группе:

1. Бот **обязательно** должен быть администратором группы
2. Группа **обязательно** должна быть супергруппой
3. Только в супергруппах пользователи могут ставить реакции на сообщения
4. Бот будет получать обновления о реакциях только после выполнения этих условий
